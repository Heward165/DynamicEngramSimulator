# Roadmap

## 0.4 preview — implemented

- Validate global sensitivity, factorial interaction, allocation-null, replay, and phased-encoding APIs.
- Compare Sobol convergence across increasing sample counts.
- Publish multi-operating-system allocation and latency baselines.

## 0.5 experiment API candidate — implemented

- Add a separate multi-region systems-consolidation contract without changing version-three checkpoints.
- Track sparse directed synapses independently from engram cell membership.
- Add explicit replay queues, interruption controls, neurogenesis rewiring, and precision-to-gist probes.
- Compare alternative consolidation families under matched inputs and seeds.

## 0.6 validation

- Calibrate summary statistics against published multi-region experiments.
- Add approximate-Bayesian parameter estimation and held-out model-family comparison.
- Publish scaling baselines for the systems-consolidation circuit.

## 1.0 stable

- Guarantee semantic versioning for public simulation and persistence APIs.
- Maintain documented migration for every checkpoint schema.
- Require a reproducible ablation report for every change to a modeled mechanism.
